# Phase 2：二维码位置管理

## 目标

让家庭整理和盘库不依赖手动在多级目录中找位置。

## 功能

- 每个位置自动获得永久位置编号，例如 FHM-LOC-000012
- 位置详情页自动生成二维码
- 二维码内容使用 fhm://location/<位置编号>
- 首页扫码后直接进入对应位置
- 物品支持手选位置移动
- 物品支持扫码移动
- 盘库页支持扫码选择盘库位置
- 每次移动写入 item_movements 历史表
- 数据库从 v1 自动迁移到 v2，不清空原有数据

## 实际家庭使用方法

1. 建好“房间 → 柜子 → 层/抽屉 → 收纳箱”。
2. 打开位置详情，打印二维码并贴在柜门、抽屉或收纳箱上。
3. 整理时需要移动物品，点“移动”后直接扫描新位置。
4. 盘库时扫描柜子二维码，立即开始核对该位置的物品。

Phase 2 仍保持 Offline First，二维码解析和库存操作不需要家庭服务器。
