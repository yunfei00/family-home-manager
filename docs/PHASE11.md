# Phase 11：v1.0 稳定性收尾

## 最终决定

目标 Android 手机上语音识别经过多种方案验证仍不稳定，包括：

- `speech_to_text`
- Android 系统语音识别 Activity
- Android `SpeechRecognizer`

为了不让一个非核心功能继续影响项目稳定性，v1.0.0 **正式移除语音识别模块**。

## 已移除内容

- 快速录入页面的“语音录入”入口
- Flutter 语音识别依赖
- Android 麦克风权限
- Android SpeechRecognizer 查询声明
- 原生语音 MethodChannel 桥接代码
- CI / 本地 bootstrap 中的语音桥接注入步骤

## 保留的快速录入能力

- 文字批量录入
- 中文数量解析
- 常用分类
- 商品条码扫描
- 识别预览
- 批量保存

## v1.0.0 稳定功能

- 家庭位置层级
- 物品管理与搜索
- 二维码位置 / 扫码移动 / 盘库
- 拍照与图片附件
- 快速批量录入和商品条码
- 高级盘库报告
- 日用品库存、最低库存、采购清单、保质期
- 完整备份 / 恢复
- 家庭服务器与多设备同步
- 自动同步与冲突保护
- AI 家庭助手
- Android 系统提醒

## 发布原则

从本阶段起功能冻结。

v1.0.0 发布后不再为了“功能齐全”继续增加模块；只有在真实家庭使用中发现明确问题时，再针对性修复。
