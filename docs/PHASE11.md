# Phase 11：v1.0 稳定性收尾

## 目标

在准备正式 v1.0 之前，先处理已知高优先级兼容问题，减少第三方依赖，并把此前遗留的语音录入问题重新纳入真机验收。

## 本阶段重点

### 1. 语音录入彻底改为 Android 系统识别

此前 Phase 4 使用 `speech_to_text`，部分 Android 手机上会长时间停留在：

`正在初始化语音识别…`

Phase 11 不再把 `speech_to_text` 作为主路径，也不再等待其初始化。

现在流程是：

1. App 直接检查 Android 是否存在系统语音识别 Activity。
2. 点击“语音录入”后立即打开系统语音识别界面。
3. 识别结果直接追加到批量录入文本框。
4. 可以连续点击多次语音录入，结果依次追加。
5. 如果手机没有系统语音识别程序，会明确显示“本机未检测到系统语音识别程序”，而不是一直卡住。

同时从 Flutter 依赖中移除了 `speech_to_text`，减少插件兼容风险。

### 2. CI 稳定性

- Android 平台继续由 CI 动态生成。
- 原生语音桥接继续通过 patch 脚本注入。
- 系统提醒桥接继续保留。
- Java setup Action 更新到 v5，消除旧版弃用警告。

## 真机验收

1. 覆盖安装 Phase 11 APK。
2. 进入“快速录入”。
3. 语音状态卡应在几秒内显示：
   - “系统语音识别可用”，或
   - 明确提示本机没有语音识别程序。
4. 点击“语音录入”：
   - 应立即出现 Android 系统语音识别界面；
   - 不应再出现长时间“初始化中…”。
5. 说：
   - “牙膏3支，口罩2盒”
6. 返回 App 后：
   - 文本框应出现识别结果；
   - 下方识别预览应同步更新。
7. 再点一次语音录入，说另一个物品：
   - 新结果应追加，而不是覆盖前面的内容。
8. 保存，确认批量物品正常写入数据库。
9. 顺带回归：
   - 条码扫描
   - 系统提醒
   - 自动同步
   - AI 家庭助手
