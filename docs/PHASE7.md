# Phase 7：家庭成员、备份与多设备同步

## 目标

让家庭管理数据不再只存在一台手机：可以完整备份、恢复，并可通过自建家庭服务器在多台设备之间同步。

## App 功能

- 顶部“家庭与备份”入口
- 家庭成员管理：管理员 / 家庭成员
- 完整 JSON 备份
- 备份包含：
  - 位置
  - 物品
  - 物品照片
  - 库存与保质期
  - 采购清单
  - 盘库记录与盘库差异
  - 移动历史
  - 家庭成员
- 从 JSON 文件完整恢复
- 恢复前有覆盖确认，避免误操作
- 家庭服务器连接配置
- 创建家庭空间，得到 Family ID + Token
- 测试服务器连接
- 上传本机完整备份
- 从家庭服务器下载并恢复
- revision 乐观锁防止两台手机静默互相覆盖
- 可复制连接信息，在第二台手机直接配置

## 同步策略

Phase 7 使用“整库快照 + revision 冲突保护”。

它适合家庭场景中的顺序同步：

1. 手机 A 修改数据并上传。
2. 手机 B 先下载最新数据。
3. 手机 B 修改后再上传。
4. 手机 A 再下载。

如果手机 A、B 都基于同一个 revision 各自修改，第二个上传者会收到冲突提示，不会静默覆盖第一台手机的数据。

后续可以在此基础上继续做记录级增量同步与自动合并。

## 自建服务器

服务端位于：

`server/`

启动：

```bash
cd server
docker compose up -d --build
```

默认端口：

`8787`

健康检查：

```bash
curl http://127.0.0.1:8787/health
```

数据默认持久化到：

`server/data/family_sync.db`

如果只在家庭局域网 / VPN 使用，可以直接配置：

`http://服务器IP:8787`

本项目当前指定家庭服务器为：

`http://106.52.122.214:8787`

App 首次打开会自动预填此地址。它当前使用 HTTP；功能可用，但公网传输的 Family Token 与备份内容没有 TLS 加密。正式长期使用建议在该服务器前增加 HTTPS 反向代理，并限制 8787 端口直接公网访问。

## 真机验收

### A. 家庭成员

1. 打开顶部“家庭与备份”。
2. 添加“爸爸”“妈妈”等家庭成员。
3. 退出 App 再进入，成员仍存在。

### B. 本机完整备份

1. 点击“导出备份”，保存 JSON。
2. 新增一个测试物品。
3. 点击“恢复备份”，选择刚才 JSON。
4. 确认测试物品消失，原备份数据恢复。
5. 检查至少一张物品或位置照片仍能显示。

### C. 家庭服务器

1. 在服务器执行 `docker compose up -d --build`。
2. App 填写服务器地址并“测试服务器”。
3. 点击“创建家庭空间”。
4. 保存 Family ID 和 Token。
5. 点击“上传本机”，revision 应从 0 变成 1。
6. 再点击“下载服务器”，数据应可恢复。
7. 在第二台手机输入同一组服务器地址 / Family ID / Token。
8. 第二台手机先下载，应得到第一台手机的数据。

### D. 冲突保护

1. 两台手机都停留在相同 revision。
2. 手机 A 修改并上传。
3. 手机 B 不先下载，直接修改再上传。
4. 手机 B 应提示服务器存在较新 revision，而不是覆盖手机 A。
