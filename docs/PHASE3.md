# Phase 3：拍照与图片附件

## 目标

让“找东西”不仅看到文字位置，还能直接看到物品和存放位置的照片。

## 本阶段功能

- 新增物品时可直接拍照或从相册选择
- 物品列表显示缩略图
- 点击物品进入详情页查看大图
- 物品详情可替换或删除照片
- 位置详情可拍摄“柜子/抽屉/收纳箱”照片
- 位置列表显示位置缩略图
- 照片复制到 App 私有文档目录，避免只保存系统临时图片路径
- SQLite v2 自动迁移到 v3，不清空已有位置、物品、二维码和盘库数据
- 无网络也能正常查看和管理照片

## 真机验收重点

1. 新增一个物品并现场拍照。
2. 退出 App 后重新打开，物品照片仍然存在。
3. 给一个位置拍照，返回位置列表能看到缩略图。
4. 替换物品照片后显示新照片。
5. 删除照片后，物品/位置记录本身仍然保留。
