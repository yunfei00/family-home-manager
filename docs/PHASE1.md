# Phase 1：可运行基础版

## 目标

先做一个能真实使用的 Android 基线，而不是一次把所有功能做完。

本阶段完成：

- Flutter App 基础结构
- 本地 SQLite 数据库
- 家庭位置树
- 物品新增与搜索
- 三种记录方式：单件、数量、箱/集合
- 按位置进行基础盘库
- 盘库结果持久化
- GitHub Actions 自动分析、测试和构建 Debug APK

## 使用流程

1. 先在“位置”中建立：房间 → 家具 → 层/抽屉 → 收纳箱。
2. 在“物品”中添加重要物品。
3. 搜索名称即可查看存放位置。
4. 在“盘库”中选择一个位置，逐项确认是否还在。

## 暂不进入 Phase 1 的功能

- 二维码生成与扫码
- 商品条码
- 拍照识别
- 语音录入
- 图片附件
- 家庭服务器同步
- 多成员账号
- 库存阈值与采购清单
- 保质期提醒

这些进入后续阶段，避免第一版过重。
