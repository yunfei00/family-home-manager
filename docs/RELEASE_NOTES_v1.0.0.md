# Family Home Manager v1.0.0

家庭物品管理 App 第一版正式稳定版本。

## 主要功能

- 家庭位置层级：房间 / 家具 / 层 / 抽屉 / 收纳箱
- 物品新增、搜索、分类与位置管理
- 二维码位置标签、扫码移动、扫码盘库
- 物品照片与位置照片
- 文字批量录入、中文数量解析、商品条码
- 高级盘库：缺失、误放、新增、历史报告
- 日用品库存、最低库存、采购清单、保质期
- Android 系统通知：库存不足、到期、同步冲突
- JSON + 照片完整备份与恢复
- 家庭服务器、多设备同步、revision 冲突保护
- 自动同步与离线容错
- AI 家庭助手、智能分类、图片识别接口

## 最终调整

语音识别功能在目标 Android 手机上经过多种方案验证仍不稳定，因此 v1.0.0 已完整移除，不作为正式功能。
