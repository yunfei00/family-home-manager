# Phase 4：快速录入

## 目标

把家庭整理时最费时间的“逐件打字录入”压缩到几秒钟。

## 本阶段功能

- 首页右上角闪电按钮进入“快速录入”
- 同一位置批量录入多个物品
- 常用分类快捷选择，也可自定义分类
- 支持“牙膏3支，口罩2盒，体温计1个”这种自然输入
- 支持常见中文数量，例如“两包”“十二袋”
- 支持语音识别后自动转成批量文本
- 支持商品条码/二维码扫描并绑定单个物品
- 条码可参与物品搜索，并在物品详情中查看
- SQLite v3 自动迁移到 v4，保留原有全部数据
- Android 构建自动补齐相机与麦克风权限

## 真机验收

1. 快速录入：选择位置，输入“牙膏3支，口罩2盒”，预览为两种物品并保存。
2. 语音录入：说出两三种物品，确认识别文本和预览。
3. 扫商品条码：扫描一件商品，输入名称后保存。
4. 在“物品”页搜索刚才的条码数字，应能找到该物品。
5. 退出并重新进入 App，刚才批量录入的内容仍存在。
