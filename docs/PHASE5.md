# Phase 5：增强盘库

## 目标

把“有没有”升级成真正的家庭盘库：知道缺了什么、东西跑到哪里、现场多出了什么，并保留可追溯的盘库报告。

## 本阶段功能

- 每个已登记物品可标记为：在这里 / 缺失 / 在别处
- “在别处”必须选择实际位置
- 完成盘库后，系统自动更新误放物品的当前位置，并写入移动历史
- 盘库现场可以直接登记“发现新物品”
- 新发现物品保存后自动加入当前盘库位置
- 盘库报告汇总：在这里、缺失、在别处、新增
- 盘库历史可查看最近记录和差异详情
- 首页盘库页展示最近盘库
- SQLite v4 → v5 自动迁移，保留既有数据
- 历史旧盘库记录自动兼容 present / missing 状态

## 真机验收

1. 在某个位置准备至少 3 个已登记物品。
2. 盘库时将其中一个标记“缺失”。
3. 将另一个标记“在别处”，选择一个新位置。
4. 点击“发现新物品”，录入一个现场新物品。
5. 完成盘库后查看报告，四类数量应正确。
6. 回到物品列表，确认“在别处”的物品位置已经自动更新。
7. 再进入盘库历史，确认本次报告仍可查看。
