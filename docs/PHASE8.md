# Phase 8：AI 家庭助手

## 目标

让 Family Home Manager 不只是“记录和查表”，而是可以直接用自然语言找东西、查库存，并在录入时帮忙分类和识别照片。

## 本阶段功能

- 顶部新增“AI 家庭助手”入口
- 可以直接问：
  - 体温计在哪里？
  - 牙膏还有多少？
  - 哪些东西快过期？
  - 哪些东西需要采购？
- 没有大模型时也可以使用本机家庭数据规则完成基础问答
- 家庭服务器增加受 Family ID + Token 保护的 AI API
- 支持 OpenAI-compatible 大模型接口
- 物品录入增加“AI 智能分类”
- AI 不可用时自动退回本机分类规则
- 拍照后可点击“AI 识别照片”
- 多模态模型可自动建议：
  - 物品名称
  - 分类
  - 单件 / 数量 / 集合
  - 简短备注
- AI 回答只使用 App 发送的家庭库存上下文，不让模型自行编造家庭物品位置

## AI Provider 配置

服务器通过环境变量连接 OpenAI-compatible API：

```bash
FHM_LLM_BASE_URL=http://host.docker.internal:11434/v1
FHM_LLM_MODEL=qwen3.5:9b
FHM_VISION_MODEL=<支持图片的模型>
```

然后重建：

```bash
cd server
docker compose up -d --build
```

如果服务器本机运行 Ollama，可将 Ollama 以 OpenAI-compatible 模式提供给容器。

如果不配置上述变量：

- 家庭问答仍可用本机规则完成找物、库存不足、到期查询
- 智能分类仍有本机规则兜底
- 图片识别会明确提示“未配置多模态模型”，不会卡死

## 当前家庭服务器

App 默认服务器：

`http://106.52.122.214:8787`

注意：当前是公网 HTTP 地址。功能测试可以使用，但 Family Token、备份和 AI 请求没有 TLS 传输加密。长期使用建议改成 HTTPS，并关闭 8787 的直接公网暴露。

## 真机验收

1. 覆盖安装 Phase 8 APK。
2. 首页右上角点击“AI 家庭助手”。
3. 不配置大模型也先问“体温计在哪里？”：
   - 如果已录入体温计，应返回其位置和数量。
4. 问“哪些东西需要采购？”：
   - 应读取 Phase 6 最低库存数据回答。
5. 新增物品，输入“儿童退热贴”，点击“AI 智能分类”：
   - 即使没有模型，也应建议“医药”。
6. 家庭服务器配置大模型后，AI 助手状态应显示模型名称。
7. 拍一张物品照片，点“AI 识别照片”：
   - 配置多模态模型时应自动回填名称/分类；
   - 未配置时应明确提示，不崩溃、不一直等待。
