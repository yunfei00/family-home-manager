# Family Home Manager

家庭物品管理、盘库、库存、同步与提醒 Android App。

## v1.0.0

项目已完成第一版功能冻结。核心目标是让家里的重要物品做到：

- **找得到**：名称、分类、位置搜索，AI 家庭问答
- **记得住**：房间 / 家具 / 层 / 抽屉 / 收纳箱层级位置
- **盘得清**：二维码盘库、缺失 / 误放 / 新增、历史报告
- **搬得明白**：扫码移动和移动历史
- **耗材管得住**：最低库存、采购清单、保质期
- **会提醒**：库存不足、到期、同步冲突 Android 系统通知
- **能同步**：家庭服务器、多设备、revision 冲突保护、自动同步
- **能备份**：JSON + 照片完整备份与恢复
- **离线可用**：本地 SQLite 为主，服务器不可用时仍可正常使用

## 快速录入

支持：

- 文字批量录入，例如：`牙膏3支，口罩2盒`
- 常用分类
- 商品条码扫描
- AI 智能分类
- 拍照 / 图片识别

语音识别由于目标 Android 手机兼容性不稳定，v1.0.0 已主动移除，不再作为正式功能。

## 技术路线

- Flutter / Material 3
- SQLite / Offline First
- Android 优先
- Python FastAPI 家庭同步服务器
- Docker Compose 部署
- OpenAI-compatible AI Provider
- GitHub Actions 自动测试与 APK 构建
