# Family Home Manager

家庭物品管理与盘库 App。

## 目标

让家里的每件重要物品都能做到：

- **找得到**：按名称、分类、位置快速搜索
- **记得住**：记录房间 / 家具 / 层 / 收纳箱
- **盘得清**：按区域或收纳箱执行盘库
- **搬得明白**：物品移动有历史记录
- **离线可用**：手机无网络也能新增、查询和盘点
- **后续可扩展**：二维码、条码、拍照识别、语音录入、库存提醒、保质期、家庭成员协作

## 技术路线

- Flutter（Android 优先，后续兼容 iOS）
- SQLite 本地数据库
- Offline First
- Material 3
- 后续增加家庭服务器同步与 AI 识别
